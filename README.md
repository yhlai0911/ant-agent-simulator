# 雙蟻資源競爭模擬實驗室

互動式 Agent-Based Model（ABM）網頁，用來模擬兩隻螞蟻在中央糖源周圍的探索、取食、接觸、迴避、競爭與攻擊。

## 線上展示

GitHub Pages 啟用後：

https://yhlai0911.github.io/ant-agent-simulator/

## 主要功能

- 開始、暫停、單步、重置與播放速度控制
- 可調整盒體積、盒高、糖源、溫度、觀察時間與時間步長
- 兩隻螞蟻可分別設定速度、體長、飢餓、感知、攻擊、迴避、耐力與力量
- 即時監看軌跡、行為狀態、傷害、取食、接觸、攻擊與資源壟斷指數
- 50–1,000 次 Monte Carlo 批次模擬
- 模擬事件 CSV、批次結果 JSON、完整設定 JSON 匯出
- 瀏覽器自動儲存與設定匯入／匯出
- 純前端、無外部套件，可離線執行

## 使用方式

直接開啟 `index.html`，或在專案目錄執行：

```bash
python3 -m http.server 8000
```

然後開啟 `http://localhost:8000`。

## 模型定位

模型尚未以特定螞蟻物種的真實行為資料校準，因此輸出代表「在目前參數與規則下的模擬結果」，不是特定物種的生物學預測。
